# Alemano Marker Scanner

Simple, self-contained repo for the Alemano Marker Scanner Android app.

Overview
- Android React Native app that detects and extracts custom visual markers.

Quick install (use the universal APK for most devices)

1. Connect an Android device (USB + adb enabled) or use an emulator.
2. Install the universal APK:

   adb install -r apk/app-universal-release.apk

Build notes
- See `SETUP.md` for full build instructions and required toolchain (Node >=18, Android SDK/NDK).
- Release APKs are in the `apk/` folder. Large APK files are stored using Git LFS.

Repository
- The repository is pushed to the configured remote (`origin/main`).

If you need anything else (strip debug files, create a smaller apk, or upload the APK elsewhere), tell me and I will do it.
